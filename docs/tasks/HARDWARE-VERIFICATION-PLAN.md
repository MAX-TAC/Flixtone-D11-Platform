# План проверки функций на железе (до проектирования меню)

Дата: 2026-11-24. Статус: **обязательный этап перед созданием UI.**

## Принцип

Ни один пункт не попадает в меню, пока не доказано, что он **работает на этом проекторе**.
Порядок: сначала тест, потом UI. Иначе получается «кнопка есть, толку нет» — ровно то,
что было с переключателем аудиовыхода в v41.

## Уровни проверки

| Уровень | Что проверено | Показывать в меню? |
|---|---|---|
| P0 — наличие | ключ/API существует | **нет** |
| P1 — запись | значение записывается и читается обратно | нет |
| P2 — применение | MediaTek/Android применил (видно в `dumpsys`) | **нет** |
| P3 — эффект | видно/слышно на экране/в звуке | **да** |
| P4 — обратимость | можно вернуть и эффект снимается | **да** |

**Только P3+P4 = функция готова для меню.**

## Блок 1: ALLM

**Почему первый:** уже `DEVICE_VERIFIED`, что дисплей заявляет `allmSupported=true`.

| Шаг | Команда | Ожидание |
|---|---|---|
| P0 | `dumpsys display \| grep mAllm` | `mAllmSupported=true` ✅ уже есть |
| P1 | `settings put global g_video__vid_allm_switch 1` | запись прошла |
| P1 | `settings get global g_video__vid_allm_switch` | `1` |
| P2 | `dumpsys display \| grep mAllmRequested` | `true` |
| P3 | Визуально: включить игру с ALLM | задержка падает (сложно измерить) |
| P4 | `settings put global g_video__vid_allm_switch 0` | `mAllmRequested=false` |

**Риск: минимальный.** Это флаг, а не режим дисплея.
**Если P2 не сработает** — значит `TvServices` не обрабатывает этот ключ, надо искать другой.

## Блок 4: Local Dimming

| Шаг | Команда |
|---|---|
| P0 | `settings get global tv_picture_video_local_dimming` |

**Особое внимание:** `VIDEOINFO_TYPE_LDM_SUPPORT`. Если `false` — функции нет на панели.
**У проектора LCOS-панель, а не LCD с подсветкой зонами.** Скорее всего LDM **не поддерживается**.

**Проверить первым делом P0: если LDM_SUPPORT=false — вычёркиваем.**

## Блок 6: Dolby Vision

**Самый сложный блок.** Порядок строго такой:

| Шаг | Что | Критерий |
|---|---|---|
| P0-1 | `getEDolbyVersion` | узнать текущую версию |
| P0-2 | Найти список допустимых версий | в DEX/ресурсах |
| P0-3 | `hwcomposer` → `dv=false` | подтвердить |
| P1 | `g_video__dovi_user_switch = 1` | записалось |
| P2 | `dumpsys display \| grep -i dovi` | изменилось? |
| P3 | **Воспроизвести DV-контент** | появился ли `DolbyVisionLogoWindow` |

**Критично:** только P3 (реальное воспроизведение) покажет, работает ли DV.
До этого — всё гадание.

**Риск: высокий.** Может дать чёрный экран.

## Порядок выполнения (когда проектор включён)

```
1. Снять базовый срез (все значения до)
2. ALLM          — 5 минут, риск мин
3. Live Tone     — 5 минут
4. IMAX          — 5 минут
5. AISR          — 5 минут
6. Local Dimming — P0: если LDM_SUPPORT=false — пропустить
7. Эквалайзер    — 15 минут, нужен слух
8. Выход звука   — 15 минут, нужен слух
9. Температуры   — 5 минут
10. DV           — только после всех, отдельным согласованием
11. Atmos        — только с ресивером
```

**Между каждым шагом — откат в исходное состояние.**

## Формат отчёта по каждой функции

```yaml
function: ALLM
level_reached: P0 | P1 | P2 | P3 | P4
baseline: "g_video__vid_allm_switch=0, mAllmRequested=false"
written: "g_video__vid_allm_switch=1"
readback: "g_video__vid_allm_switch=1, mAllmRequested=true"
effect: "не измерено визуально"
rollback: "возвращено в 0, mAllmRequested=false"
verdict: READY_FOR_MENU | NOT_SUPPORTED | NEEDS_MORE_DATA
```

**Только `READY_FOR_MENU` идёт в UI.**
