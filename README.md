# Flixtone D11 Platform — модернизация прошивки проектора

Рабочий репозиторий проекта модернизации стоковой прошивки проектора **FlixTone D11 Master (machine id `8054`)**.

Цель: привести штатное ПО проектора в чистый вид и построить полноценное Android TV меню настроек,
в котором управление функциями проектора (фокус, трапеции, источник света, изображение, звук, MEMC/HDR,
охлаждение, где это возможно) и системой живёт в одном месте — без китайского GUI `com.my.settings`.

---

## Дисциплина доказательств (обязательно для любых документов и отчётов)

Каждое утверждение в этом репозитории обязано иметь уровень достоверности:

| Уровень | Что означает | Чего НЕ означает |
|---|---|---|
| `DEVICE_VERIFIED` | Проверено на живом 8054, с приложенным сырым выводом и датой среза | Что поведение сохранится после смены входа/режима/перезагрузки |
| `STATIC_CONFIRMED` | Подтверждено чтением кода/ELF/манифеста/конфига с указанием файла и sha | Что функция реально вызывается на устройстве |
| `BUILD_TESTED` | Сборка/CI/юнит-тесты прошли | Что APK установлен и работает |
| `ASSUMPTION` | Гипотеза, требующая проверки | Не является фактом, не должно попадать в UI как факт |

Правила:
1. Утверждение без уровня считается `ASSUMPTION`.
2. `SOURCE_IMPLEMENTED` ≠ `BUILD_TESTED` ≠ `DEVICE_VERIFIED`. Уровни не переносятся автоматически на новый билд.
3. Любой аппаратный эффект (картинка, звук, оптика, охлаждение) подтверждается только `DEVICE_VERIFIED` с протоколом «до / действие / после / откат».
4. Расхождения между документом и реальностью (дрейф) фиксируются как errata, а не переписываются молча.

## Структура

```text
docs/            документы проекта: архитектура, карты, планы, решения (ADR)
research/        доказательная база: дампы, выводы, сравнения, эксперименты
mod/             исходники модернизированных приложений (позже)
firmware/        манифесты разделов, план сборки, схема восстановления
tools/           скрипты диагностики и сборки
reports/         отчёты прогонов (сырые, с датой и device fingerprint)
```

## Правила безопасности

Никогда без отдельного письменного согласия владельца:
`fastboot flash/erase/lock`, `dd of=/dev/block/*`, `pm clear`, factory reset,
запись `persist / eeprom / private / tvcertificate / factory / tvconfig / mboot / optee`.

Публиковать в этом репозитории запрещено: приватные калибровочные разделы, серийники,
MAC, ключи, DRM/HDCP-материалы, учётные данные.

|---|---|---|---|---|
