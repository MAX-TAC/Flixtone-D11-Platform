# ADR-0001: Один рабочий репозиторий вместо наведения порядка в старых четырёх

- Дата: 2026-11-23
- Статус: принято
- Контекст: за проект работало несколько ИИ-агентов, в четырёх старых репозиториях накопился
  документационный мусор и противоречия (см. errata ниже). Владелец предложил либо привести старые
  репозитории в порядок, либо завести новый.

## Решение

1. Новый репозиторий `Flixtone-D11-Platform` — **единственное место, где ведётся текущая работа**.
2. `MAX-TAC/Projector-Soft` — **замораживается** как исторический архив (PR #1–#10 не трогаем).
   Из него берём только проверенный код и идеи, с указанием commit SHA.
3. `MAX-TAC/FlixTone_8054_Backup` и `MAX-TAC/Everycom-Cinelux-Firmware` — остаются
   **архивом доказательств**: дампы, PKG, OTA, сравнительные анализы. Не переструктурируются.
4. `MAX-TAC/Firmware-CN-Projectors` (Touyinger ET32) — вне области работ, только как внешний опыт.

## Последствия

- Нет миграции 300+ файлов и рискованных переписываний старых репозиториев.
- Каждый документ здесь имеет собственный уровень достоверности (см. README).
- Устаревшие утверждения старых репозиториев не наследуются автоматически: их нужно перепроверять
  и переносить сюда уже с уровнем.
