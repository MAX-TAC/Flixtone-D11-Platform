# Задание: MOD v43 — финальная сборка

Дата фиксации: 2026-11-24. Владелец: MAX-TAC. Решение принято, меняется только по явному запросу.

## Что считается готовым результатом

Сборка принимается, если **все пять пунктов** выполнены:

1. **Устанавливается как обновление** стокового `com.android.tv.settings` (подпись платформенная, поверх `/data/app`, без удаления системы).
2. **Главный экран выглядит как v41 владельца** — то же расположение пунктов, тот же вид.
3. **Заводское (китайское) меню вырезано** из приложения — нет KuSettings-пунктов, нет заводских экранов внутри MOD.
4. **Все переключатели и ползунки работают** — не просто отображаются, а применяют значение.
5. **Новые функции добавлены** и проверены на устройстве.

## База сборки

| Параметр | Значение |
|---|---|
| Исходная ветка | `feature/8054-v41-picture-sound-safety-20261122` |
| Рабочая ветка | `mod/v41-bt-eq-gamemode` |
| Workflow | `build-tvsettingsplus-inline-v42-bt-eq.yml` |
| Флаг патча | **`--exact-8054`** (обязателен) |
| Подпись | платформенный AOSP ключ из `aosp-mirror/platform_build` |
| Стоковый APK-база | `vendor/reference/8052/APK/TvSettingsPlus.apk` (байт-идентичен 8054, кроме подписи — проверено) |

## Что НЕЛЬЗЯ трогать

| Запрет | Причина |
|---|---|
| **Прозрачный фон левой панели** | Требование владельца. Фон не под меню — всегда прозрачный. |
| **Ползунки изображения, открывающие нижнюю панель регулировки** | Требование владельца. Их поведение менять нельзя. |
| **Расположение пунктов главного экрана** | Владелец оставляет свой вид v41. |

## Что нужно вырезать

| Что | Где искать |
|---|---|
| Пункты, ведущие в KuSettings (`com.my.settings`) | `OemHardwareDelegatedSettings`, `*Delegated*` |
| Заводские экраны внутри MOD (factory menu) | `*Factory*`, `*Oem*Factory*` |
| Пункты, ведущие в китайское меню настроек | `uicustom.*`, `com.my.settings.*` |
| Нерабочие заглушки | пункты, чей обработчик только пишет в лог |

## Новые функции, которые надо добавить

| Функция | Раздел | Статус проверки |
|---|---|---|
| **Эквалайзер для BT** (`audiofx.Equalizer`) | Звук | ✅ работает на саундбаре |
| **Выход звука** (Авто/Динамики/BT/HDMI-ARC/Линейный + дублирование на динамики) | Звук | 🔧 требует UID 1000 |
| **Игровой режим** (низкая задержка) | Источники | ✅ ключ принимается |
| **ALLM** (авто-игровой) | Источники | 🔶 не проверен |
| **AISR** + демо-режим | Изображение | 🔶 не подтверждён |
| **Live Tone** | Изображение | 🔶 не подтверждён |

## Что уже проверено на устройстве (не перепроверять)

| Функция | Уровень |
|---|---|
| Насыщенность / контраст / яркость / резкость | ✅ видно |
| HDR вкл/выкл | ✅ видно |
| Эквалайзер `audiofx` на Bluetooth | ✅ слышно |
| `setPreferredDevicesForStrategy` без UID 1000 | ❌ InvocationTargetException |
| ALLM через `g_video__vid_allm_switch` | ❌ `mAllmRequested` не меняется |
| Local Dimming | ❌ невозможен (1LCD, один LED) |

## Известные баги, которые надо исправить

| Баг | Симптом | Причина |
|---|---|---|
| **Меню не строится** | стоковый экран вместо MOD | `install()` получал View и падал на `getPreferenceScreen` |
| `getPreferenceScreen` не публичный | `NoSuchMethodException` | нужен обход иерархии (`callDeep`) |
| `TYPE_SPDIF` | сборка падает | появился в API 34, проект на API 33 |
| `--version-code 42` | сборка падает | скрипт `compose_brightness_v3_apk.py` имел жёсткий список |

Все четыре уже исправлены в ветке `mod/v41-bt-eq-gamemode`.

## Порядок работы

1. Аудит текущего состояния MOD (что есть, что мертво).
2. Вырезание мусора.
3. Добавление новых функций.
4. Сборка и установка.
5. Проверка владельцем.
