### Ограничения среды разработки

- `curl` / `Invoke-WebRequest` / Python из песочницы не завершают TLS-хендшейк
  (`SEC_E_NO_CREDENTIALS`). Работа с GitHub идёт через `git` (с `http.sslBackend=openssl`).
- `ssh-keygen`/`openssl.exe` из Git for Windows в песочнице не запускаются (нет signal pipe).
- Встроенный adb-инструмент среды не видит устройство; используется `C:\Program Files\platform-tools\adb.exe`.
