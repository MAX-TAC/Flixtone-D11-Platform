# Задачи по звуку (из запроса владельца 2026-11-24)

Уровень: задача, не факт. Требует реализации и проверки на устройстве.

## T-AUD-01: Отдельный эквалайзер для каждого выхода

**Требование:** если подключён саундбар — его профиль EQ; если звук из динамиков проектора — свой.

**Обоснование владельца:** сейчас EQ действует только на встроенные динамики, на саундбар не влияет.

**Техническая основа (`STATIC_CONFIRMED`):**
- OEM уже разделил EQ по источнику: `APP_CFG_AUD_BBE_EQ_BAND_TV_1..5` и `..._AV_1..5`.
- Нужно добавить разделение по **выходу**: `AUD_OUTDEV_SPEAKER` / `AUD_OUTDEV_BLUETEETH`.
- Хранение профилей — в нашем приложении (SharedPreferences), подстановка при смене выхода.

**План:**
1. При смене выхода (через `SoundSpeakerStatusService` broadcast `android.settings.SOUND_SPEAKER_STATUS`)
   считать текущий выход.
2. Загрузить сохранённый профиль для этого выхода.
3. Записать в `sound_equalizer_detail_*hz` (+ группы `AV`/`TV` при необходимости).

**Риск:** средний. Требует проверки, применяется ли запись при активном BT.

## T-AUD-02: Переключатель вывода звука

**Требование:** в настройках звука — переключатель «Динамики / Саундбар».

**Почему не сработало в v41 (`STATIC_CONFIRMED`):** писали только в Android-слой.
Слоёв три, и третий перетирает первый:

```
1. Android:  AudioManager.setPreferredDevicesForStrategy()
2. OEM:      g_audio__aud_out_port = AUD_OUTDEV_SPEAKER / AUD_OUTDEV_BLUETEETH
3. Статус:   sound_speaker_status  ← SoundSpeakerStatusService перезаписывает
```

**План:**
1. Писать в слой 1 и слой 2 **вместе**.
2. Проверять результат по `dumpsys audio | grep Devices:`, а не по флагу.
3. Если `Devices:` не совпадает с намерением — показывать «не удалось», не «включено».

## T-AUD-03: Блок Dolby Atmos — только когда Atmos активен

**Требование владельца:** пометить, что в проекторе есть Atmos, и показывать его настройку
только когда Atmos работает.

**Основа (`STATIC_CONFIRMED`):**
- `"atmosEnabled . dapValue="` — состояние Atmos берётся из DAP.
- `AUDIO_INFO_GET_TYPE_DAP_LEVELER / VIRTUALIZER / DE_ENABLE / DE_AMOUNT / DE_DUCKING`.
- В ARC-профиле: `ddp:0(atmos:0)` — Atmos не согласован, пока eARC не поднят.

**План:**
1. Читать `atmosEnabled` / `dapValue` из DAP.
2. Показывать блок Atmos **только** при `true`.
3. Иначе — скрыть или показать «недоступно: требуется eARC + Atmos-ресивер».

## T-AUD-04: Два Bluetooth-устройства одновременно (наушники для двоих)

**Требование владельца:** смотреть проектор вдвоём, каждый в своих наушниках.

**Техническое состояние (`DEVICE_VERIFIED`):**
- `MaxConnectedAudioDevices: 5` — про количество подключённых, **но не про одновременное воспроизведение**.
- `mA2dpOffloadEnabled: false`.
- В `dumpsys` каждый стрим имеет одно устройство.

**Что нужно для реализации:**
1. `AudioPolicy` с двумя одновременными A2DP-выходами.
2. Поддержка двух активных A2DP-соединений на уровне Bluetooth-стека.
3. Патч фреймворка или конфигурации.

**Оценка:** **низкая вероятность** без правки фреймворка. Отложено до этапа прошивки.

## T-AUD-05: 5-полосный vs 13-полосный эквалайзер

**Ответ (справочно, `STATIC_CONFIRMED`):**

| | 5-полосный (BBE EQ) | 13–20-полосный (DAP GEQ/IEQ) |
|---|---|---|
| Технология | BBE Sound DSP | Dolby Audio Processing |
| Ключи | `g_audio__aud_bbe_eq_mode` | `E_MTK_FAPI_KEY_TYPE_DAP_BAND_GEQ_TARGET_*` |
| Полос | 5 | до 20 (`MAX_GEQ_BAND_NUM`) |
| Параметры полосы | только gain | **частота + gain + Q + тип** |
| Разделение по источнику | да (`TV` / `AV`) | нет |
| Где виден | пользовательские настройки | заводское меню |

**Вывод:** 5-полосный — то, что видит пользователь, простой графический EQ.
13+ — полноценный параметрический EQ Dolby, спрятанный в заводском меню.

Для серьёзной настройки звука надо использовать **DAP GEQ**, а не BBE.
