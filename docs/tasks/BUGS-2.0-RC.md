## Общая причина 3.5 / 5.1: переключатели не обновляются

Во всех моих SwitchPreference обработчик возвращает `false`, а локально
`setChecked` не вызывается. Android в этом случае **откатывает** визуальное
состояние к прежнему, потому что `onPreferenceChange` вернул false.

**Правильный паттерн:**

```java
row.setOnPreferenceChangeListener((pref, value) -> {
    boolean on = (Boolean) value;
    boolean ok = Settings.Global.putInt(cr, KEY, on ? 1 : 0);
    int read = Settings.Global.getInt(cr, KEY, -1);
    ((SwitchPreference) pref).setChecked(read == 1);   // ← синхронизировать
    return false;   // не даём Android самому менять
});
```

Или просто `return true`, если запись точно удалась. Первый вариант надёжнее.
